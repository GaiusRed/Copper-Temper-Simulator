# CopperTemper

CopperTemper simulates Minecraft equipment tempering from versioned catalogs.

## Commands

Run the test suite:

```text
npm test
```

Validate the bundled catalogs:

```text
npm run validate:catalogs
```

Create a production build:

```text
npm run build
```

Catalog files are in `src/catalog/data/`.

Production ingredient, card, and trait catalogs require separate approved content specifications.
